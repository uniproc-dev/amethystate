# What closes in one sitting

Beside `TODO.md`, which holds the questions that need deciding before anything
can be written. These need no deciding - they are known, the shape of the fix is
known, and each is an afternoon at most. They are here so that being small does
not mean being forgotten.

An entry leaves when the code settles it, the same way it does next door. An
entry that turns out to want a decision, or to be larger than an afternoon,
leaves the same way - for `TODO.md`, restated at the size it really is. Nothing
stays here to be looked past.

*Empty.*
